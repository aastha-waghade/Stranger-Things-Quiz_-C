# Stranger Things Quiz Game in C

A simple console-based quiz game developed in C based on the popular Stranger Things series. The game tests the player's knowledge through 10 multiple-choice questions and calculates the final score.

## Features

- Player name input
- Main menu
- Start Quiz option
- Instructions option
- Exit option
- 10 multiple-choice questions
- Automatic score calculation
- Final score display
- Different performance messages based on score
- Quiz can be played multiple times

## Technologies Used

- C Programming Language
- GCC Compiler
- Visual Studio Code

## Project Structure

```text

````

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/aastha-waghade/Stranger-Things-Quiz.git
```

### 2. Open the Project

Open the project folder in Visual Studio Code or any C-supported IDE.

### 3. Compile the Program

Open the terminal and run:

```bash
gcc main.c -o quiz
```

### 4. Run the Program

On Windows:

```bash
.\quiz.exe
```

## How the Game Works

1. The player enters their name.
2. The main menu is displayed.
3. The player can choose:

   * Start Quiz
   * Instructions
   * Exit
4. The quiz contains 10 questions.
5. Each correct answer gives 1 point.
6. The final score is displayed out of 10.
7. The player can start the quiz again or exit the game.
